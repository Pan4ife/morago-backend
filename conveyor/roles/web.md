# Роль: web (веб-клиент)

**Делает:** браузерный клиент — HTML/CSS/JS без сборщика в `src/main/resources/static/`. Spring Boot раздаёт его сам.
Общается с сервером только через существующий REST API и Socket.IO-сигналинг (`docs/socketio-events.md`).

**Не делает:** серверный код. Не хватает эндпоинта — СТОП и вопрос (это задание роли backend).

**Готово, когда:** сборка зелёная, страница открывается, сценарий из «Чек-лист для глаз» проходит руками.
